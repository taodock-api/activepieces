# Taodock for Activepieces

Use the AI models available to your Taodock API key in Activepieces flows and AI agents. The piece discovers authorized models at runtime instead of keeping a static model list.

## Actions

- List Models
- Generate Image
- Create Video Task
- Get Video Task Status
- Download Video
- Custom API Call

Image and video generation consume Taodock quota. Model availability and supported request fields depend on the connected API key and the selected model.

## Install

In Activepieces, open **Settings → My Pieces → Install Piece**, choose the npm option, and enter:

```text
activepieces-piece-taodock
```

Create a Taodock API key at <https://taodock.com/keys>, then add it as a connection in Activepieces.
